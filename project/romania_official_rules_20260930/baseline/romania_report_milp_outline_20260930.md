### 第7章必须覆盖的基本面专题

1. 数据来源、覆盖与时间/单位。实际、预测、计划、结算分别标识。
2. 装机结构与变化：2023/2024/2025年末及2026可得截面；储能MW/MWh分列，分布式口径明确。
3. 负荷：季节/月份/工作日/钟点、峰谷、持续曲线、爬坡和极值。
4. 分电源实际出力：核、煤/褐煤、气、水、抽蓄发电/抽水、风、光及其他；不可用细分按官方分类保留。
5. 残余负荷：候选定义RL=总负荷−风电−光伏；先核负荷和分布式发电覆盖，避免重复扣减。核、水或净进口调整另建指标，不能混称同一个RL。
6. 现货电价：均价、分位数、波动、低/负价、峰谷差、价量关系、DA—IDA关系；区分量加权价与时间均价。
7. 残余负荷、电源结构、跨境交换与价格：同轴典型日、散点和分箱、季节比较；关联不证明某电源设定价格。
8. 报价与边际技术：先验证公开数据是否含技术身份；只有聚合曲线时不得声称识别定价机组。
9. 各产品容量需求/报价/中标与价格、激活方向/量/价格、不平衡价格及跨市场关系。
10. 制度切换前后可比性、数据质量及对储能策略的含义；不把极端系统价格直接当可实现电池收入。

## 3. 建议的模型分层

| 层级 | 候选范围 | 所需条件与解释 |
|---|---|---|
| M0 | 物理储能加日前 | 作为可对账基准；先验证能量守恒、时长、SOC和2h/4h公平性 |
| M1 | 日前加IDA | 逐轮报价与结果时序完备；保留已成交承诺、增量头寸和手续费 |
| M2 | M1加已确认的备用容量与激活 | 优先研究aFRR，mFRR/FCR是否进入由资格、机制和数据决定；不得以西班牙排除范围替代罗马尼亚判断 |
| M3 | 现实信息滚动与连续日内等扩展 | 需要历史可见预测、成交/深度数据与项目履约证据；不能仅把优化窗口缩短就称真实回测 |

这些是同一数学体系的范围层级，不是现已获准开发的版本。模型复杂度取决于已验收证据，不要求所有产品一次性联合。

## 4. 必须逐项决定的假设

| 候选ID | 待定内容 | 要求 |
|---|---|---|
| RO-A01 | 价格接受者与成交假设 | 理想成交、滑点、数量上限分别说明；不等于历史报价一定中标 |
| RO-A02 | 2h/4h工程参数 | 同P、同效率/SOC/可用率比较或明确差异；可用MWh和额定MWh分开 |
| RO-A03 | 备用容量接受 | 不以系统需求/报价比直接充当本站概率；若采用代理，注明条件并做敏感性 |
| RO-A04 | 激活映射 | 公共系统比例、压力路径或站级数据分别定义；上下调过程不能仅净额抵消 |
| RO-A05 | 初末SOC和滚动视野 | 2日优化/1日执行可作为ES对照候选，须独立决定；内部窗口不任意重置SOC |
| RO-A06 | 循环与退化 | 不自动继承600EFC/年等ES数值；分母、吞吐和费用是否重复计入说明 |
| RO-A07 | 费用、税和汇率 | 毛现金收益与扣已建模成本后的净额分别输出；免征需要正式证据 |
| RO-A08 | 信息条件 | 完美信息结果称事后条件基准；若未证明全期最优，不称严格全期上界 |
| RO-A09 | 缺失与断段 | 不把未知状态当空闲，不跨未知区间无条件继承SOC；重启边界和末端估值明确 |

假设状态目前均为候选，只有研究和策略阶段登记、审核后才能纳入正式模型。

## 5. 数学与后续实现的验收重点

1. 电量守恒：任一现金收入对应实际交付、容量承诺或结算调整；不能有激活收入但无功率/SOC变化。
2. 备用可交付：上下调能力与基准出力、充放跨零、并网方向和资格一致；同时出售不同产品时不重复占用同一能力。
3. 过程SOC：同一QH先上后下或先下后上可能不同；净激活为0不证明全过程可行。
4. 交易事件：容量结果未知时不能用于此前决策；关门后不能撤销已成交承诺；小时产品不拆成独立QH订单。
5. 结算：正/负现货价、上/下调能量、偏差、容量每块/每小时计费分别手算；损耗和回送免征边界保持一致。
6. 滚动：SOC、未交付订单、备用义务和循环剩余额度结转；仅执行段结算，观察日和终端价值不重复计收益。
7. 数据：DST、版本切换、缺失月份和修订重跑可追溯；最终结算与当时决策信息分开。
8. 2h/4h比较：同历史样本、规则版本、信息条件、求解设置与费用；分别报告每MW/每MWh，功率假设明确。
9. 验证层次：数学手算通过不等于代码通过，代码测试通过不等于真实收益验证；报告各自状态。

## 6. 最终交付的完成标准

研究报告完成需有足够官方证据、基本面数据与可复现分析、明确未决边界以及研究审核。MILP说明完成需有完整变量/公式/单位、来源追溯、策略和数学审核、输入输出规范及手算验证。两份文档可以先于代码和历史收益测算交付；第9章如尚无计算结果必须如实标明，不把研究规划或数学设计标为收益验证完成。
