## 输入合同

默认读取`data/processed/RO/prices_eur_v1_20261002/`及manifest核验后的正式/观察CSV。时间必须UTC唯一连续15min；当地日由Europe/Bucharest独立重算；原生DA ID及60/15min步长、价格必须在完整合同内一致；容量整小时4QH。全部价格字段EUR，容量EUR/(MW·h)，激活EUR/MWh保持原符号。FX已在数据层换算，求解器不再换汇。

数量/价格非有限、alpha无效和缺失分别保存；独立重算三相比值及整小时门禁，交叉校验输入标记。不能依赖CSV中的True而跳过必要价格、系统量、FX和时标检查。FCR从2025-06起范围内有效订单启用。禁用市场不生成未知系数乘0。

参数：P默认100MW，H=2或4；Emin/Emax=5%/95%名义能量、初末Emin、效率0.92、FCR缓冲0.5h。首版对称充放/接网均P。aFRR/FCR资格带宽显式参数，研究默认P；FCR单元上限默认ceil(P/20)个均分研究单元，可显式提供不大于20MW的列表、总量不大于P。该列表不代表真实认证。新订单整数容量受M03系统量、资格和设备上限限制。

容量09:00关闸/10:00结果，DA13:00/14:00，均D−1当地时间，为A05名义时表。首日过去关闸无历史订单置0；以后缺冻结键报错。对完全已冻结首日按P01审计并常数化，第二日是自由后缀。不通过允许自由充电来修复冻结路径。

年度预算一次确定并写入manifest。默认以共同比较组包含DA为基准，按DA有效、物理状态可连续构造的掩码按M23生成；不得随是否增加aFRR/FCR、p、H改变。允许显式提供同一比较组年度预算以复现其他固定覆盖；必须非负、有限、覆盖窗口年份，且不超过相同正式期完全覆盖上限。观察日不生成同年额外预算，跨新年只生成lookahead_only额度。EFC分母随各自可用能量缩放。

## 求解与独立验收

默认SciPy/HiGHS MILP、稀疏矩阵，紧凑P01—P07；另保留独立C/D、逐相位二元的reference构造供等价回归。不开启未证明必要的有序符号强化。保留首日常数现金，重算原目标尺度gap；记录列/行/非零、连续/整数/二元数量、建模/求解/审计时间、节点、bound和原始gap。默认单窗30秒、mip_rel_gap=1e-4，presolve可配置，不保证每次精确最优。

数值验收：MW/MWh绝对容差1e-6；整数1e-6；现金/目标1e-5 EUR加1e-9相对误差；EFC1e-7。alpha原始非负及和≤1使用严格比较，不借数值容差放宽。仅对求解器整数在容差内回整并重新完整审计；持续失败即阻断。

独立审计从订单及原始输入重建事件余量、每相功率、SOC端点、FCR双向缓冲、EFC、现金、终态与冻结向量，不复用矩阵行作唯一证据。限时可行解只有通过全部审计才可提交；无可行解、未知字段与非零承诺冲突、原始审计失败均不提交本日。

## 输出与原子性

输出到全新目录：配置/来源哈希/运行版本manifest、逐窗指标、执行QH现金及数据覆盖、逐相SOC/EFC、完整订单及FCR单元分配、月度六项现金与kEUR/MW、年度预算/已执行EFC、检查点、失败诊断及简短结果MD。六项为DA、FCR容量、aFRR容量上/下、aFRR激活上/下。首日未承诺与数据失效分别标记，未参与策略现金0不把源价格null改成0。

窗口先求解和独立验收，再构造全部新增状态；每窗记录同时包含执行轨迹、今日关闸的次日订单和新检查点，单文件原子替换/发布后再更新内存。禁止覆盖既有成功窗口；崩溃恢复只读取已完整提交窗口链，检查输入、代码、配置、预算与冻结哈希。输出中观察日只能是计划，不进入正式执行现金或累计EFC。检查点恢复不静默跨数据/代码/参数版本。

本轮先合成边界、紧凑/reference等价及真实数据代表窗口验证，再交reviewer；不将实现测试或短样本称为全期收益验收。后续大规模运行可用同一CLI另存新目录。
