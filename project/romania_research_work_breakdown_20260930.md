# 罗马尼亚独立储能研究分步骤工作明细

日期：2026-09-30。配套[研究基线](romania_research_plan_20260930.md)、[数据清单](romania_data_acquisition_plan_20260930.md)、[报告与MILP提纲](romania_report_milp_outline_20260930.md)。

本文将五个总体步骤继续拆成可执行子任务。每项说明具体操作、需要留下的成果和完成判据，使“研究某市场”落实为查文件、提取规则、核数据、解释机制和形成模型依据。以下均是待执行的研究设计，不代表规则已经确认、文件已经下载或模型已经通过审核。

已确认范围保持不变：2025年1月至2026年8月，通用独立电化学储能，比较2小时与4小时；功率暂为参数。全文的数值样例仅用于说明工作方法，不作为罗马尼亚规则或项目参数。

## 阅读方式与任务对应

| 五个步骤 | 对应原任务包 | 要回答的问题 | 阶段成果 |
|---|---|---|---|
| 1 官方规则研究 | RO-01—05 | 谁能参加、何时交易、如何履约、怎样收付款？ | 规则证据表、资格矩阵、时间线和结算链 |
| 2 数据样本验证 | RO-06前半 | 官方数据能否取得、字段实际代表什么、能否相互对齐？ | 样本原件、数据字典、质量记录和下载路线 |
| 3 全期数据与分析 | RO-06后半、RO-07 | 20个月市场有什么特征、哪些数据足以支持建模？ | 全期数据、图表、覆盖报告和解释边界 |
| 4 研究报告与审核 | RO-08 | 研究结论是否完整、可追溯，哪些市场允许进入下一阶段？ | 研究报告、问题关闭记录、限定范围验收 |
| 5 策略、MILP与输入输出 | RO-09—10 | 把已确认机制转成什么决策、公式和数据接口？ | 策略说明、MILP数学文件、输入输出规范 |

步骤1和2可以互相校验；步骤3的某一数据集须在对应样本通过后展开。步骤4通过后，步骤5内部仍严格遵循“策略审核→数学模型审核→输入输出规范”。本次终点是研究报告与数学/输入输出文档，代码、收益测算和运行验证另按项目门禁执行。

## 1. 官方规则研究

### 1.1 建立官方文件目录和历史版本表

**向下执行：**

1. 按“许可与并网、现货、平衡容量、平衡能量、偏差、费用”建立文件清单；从既有来源表进入ANRE、OPCOM、Transelectrica和ENTSO-E官方入口。
2. 保存法规、实施程序、市场规则、参与合同、操作手册和修订通知；记录谁制定、谁批准、谁执行，区分正式文件与咨询稿。
3. 查找2025年1月之前已生效且仍适用的基础文件，再补2025—2026年的修改；只查研究期内公布的文件会漏掉有效基础规则。
4. 分别记录公布日、生效日、系统实际实施日、废止日和适用产品；公告只写预计实施的，不能填成真实投产。
5. 将每条关键要求登记为RO-R规则，连接RO-S来源，保留原文定位和中文释义；有冲突时列RO-U问题。

**产物与判据：**形成来源索引和版本时间线。任一模型候选规则必须能回答“依据哪一条、对谁适用、在哪段历史期适用”；缺版本或定位就保持待确认。

### 1.2 画清机构和参与主体关系

**向下执行：**

1. 查监管、市场组织、系统运行、输配电、计量、结算等职责及适用交易场所，不把不同机构的职责合并成“交易所”。
2. 建立资产所有者、市场交易主体、聚合商、平衡服务提供者BSP、平衡责任主体BRP之间的合同和责任关系。
3. 查询官方主体和合格资源名册；记录快照日期，按法人、许可证、资源或代码分别去重，不混用数量。
4. 画出“电池→代理/聚合商→交易市场→系统运营商→责任主体”的数据、指令、现金流关系；同一法人兼任角色仍分角色解释。

**产物与判据：**机构责任图、主体名词表和名册口径表；能够指明谁报价、谁收款、谁接调度、谁承担偏差及罚款。完整数量无法核实时保留未知。

### 1.3 拆解独立储能进入市场的路径

**向下执行：**

1. 分别查项目建设/运行许可、并网、计量、充放电身份、市场注册、BRP安排、BSP资格与产品预认证。
2. 对直接参与、委托交易、聚合参与列出所需合同、数据接口和责任边界。
3. 逐产品提取最小申报规模、数量步长、响应时间、持续能力、遥测、控制、测试、可用性及暂停资格条件；未查到的项目明确留空并列问题。
4. 比较2h/4h项目：先区分名义时长与可交付时长，再检查哪些条件取决于功率、能量、SOC、接网或聚合池，而非仅看E/P。
5. 将要求标为“市场普遍要求”“产品要求”“具体项目参数/合同条件”，避免把项目假设写成法律要求。

**产物与判据：**准入流程和“产品×资格要求×证据×2h/4h影响”矩阵。产品具有收益入口不等于本项目已经具备资格。

### 1.4 分开研究日前、日内拍卖和连续日内

**向下执行：**

1. 为三个交易环节分别建规则卡：申报对象、报价单位、订单类型、最小数量、报价粒度、交付粒度、价格界限和成交机制。
2. 提取开市、关门、结果发布、计划提交与修改截止时刻；写清官方时钟和夏令时安排，并转换到统一事件时间线。
3. 查不同交易环节的买卖是否作为增量叠加，怎样转成最终交付计划，何时可以反向交易或调整。
4. 查耦合、跨区容量、停市、取消、解耦及回退机制，对异常日另建标志。
5. 查交易费用、担保、支付周期、结算币种和结果更正；把“一般参与成本”和“逐MWh费用”分开。
6. 逐版本确认历史合同粒度；小时合同落在四个QH物理时段时，保留一笔合同对应多个执行时段的关系。

**产物与判据：**三类市场规则卡和时序表。能够描述一笔交易从报价到交付的完整过程，并确定后续模型何时可以改变哪个变量。

### 1.5 对每种辅助服务分别研究容量采购

**向下执行：**

1. 从官方本地产品出发，核实与FCR、aFRR、mFRR及其他服务的对应关系，不能仅凭名称相似映射。
2. 查是否采购付费备用容量、谁采购、需求如何公布、拍卖频率、交付块长度、上下方向是否分开或成对。
3. 提取报价数量/价格、最低块、可分割性、出清方式和支付价格；区分逐报价支付、统一价格、统计均价等概念。
4. 查中标后是否必须提交能量报价、保持哪些可用功率、能否修改/转让/退出承诺，以及未履约处理。
5. 查多个产品之间能否同时承诺同一能力、同一产品上下方向是否有关系、交付时间重叠时如何限制。

**产物与判据：**逐产品容量采购表。必须能写出“什么数量×什么价格×什么计费周期”，并明确该收入对应的履约义务。

### 1.6 对每种辅助服务研究激活和欧洲平台接口

**向下执行：**

1. 查能量报价是否与容量中标绑定，是否允许无容量合同的能量报价，谁决定激活、能否拒绝及何时更新报价。
2. 分清系统需求、激活指令、接受报价、实际响应和最终结算量；调查是否发布资源级记录。
3. 提取响应、爬坡、持续与恢复要求，明确上调可由增发还是减充提供，下调同理；具体允许路径需官方证据。
4. 查方向、能量定价、负价及履约考核；单独确认激活能量如何调整BRP的偏差账本。
5. 核查PICASSO/MARI等平台的成员、计划、实际接入及中断状态；分别解释本地容量采购和跨区能量交换的关系。

**产物与判据：**“报价→激活→物理响应→计量→付款”流程及产品/平台版本表。无法确认单站激活分配时，不能把系统总量写成本站规则。

### 1.7 重建偏差与完整现金结算

**向下执行：**

1. 找到最终有效计划、实际计量、已分配平衡能量、其他调整项的官方定义，确认偏差归属于哪个主体。
2. 核查结算周期、方向符号、价格方式、初步/最终版本、修订和争议处理。
3. 建立电量桥接表：起始成交计划→后续增量交易→激活调整→实测→剩余偏差；每项标明来源和单位。
4. 建立现金科目表：现货买卖、容量报酬、激活能量、偏差、未交付费用、交易/聚合/网络费用。
5. 设计无激活、仅上调、仅下调、双向激活、实际交付不足、负价格等手算案例；先以符号表达，规则确认后再用假设数字验证。

**产物与判据：**电量桥接、现金账本和手算例。每笔电量有唯一清楚的结算处理，不能同时作为激活收益和未经调整的偏差重复记账。

### 1.8 逐项核验费用与减免

**向下执行：**

1. 列出输电、配电、系统服务、交易、聚合、担保相关费用及税务口径；标明固定费、按功率费、按能量费。
2. 对储能减免寻找正式法规与实施程序，确认受益主体、适用电量、计量要求、申报方式和历史生效期。
3. 分别检查充入电量、回送电量、损耗、辅助用电的收费处理，不能只设一个“充电费率”。
4. 识别费率是否随接网位置、电压、月份或合同变化；通用项目无法确定的，设计参数项和敏感性。

**产物与判据：**“收费对象×计费基数×费率×适用期×来源”表。毛现金收益、扣已建模费用后的收益以及尚未计入的成本范围可明确区分。

**步骤1退出条件：**核心规则有证据和历史适用期；形成可解释的准入、时序和结算链；缺口明确影响哪些产品。没有进入模型的正式放行，完整研究仍需步骤4审核。

## 2. 数据样本验证

### 2.1 把研究问题转换为数据字段

**向下执行：**

1. 对数据清单D01—D19逐项填写“用于哪章、哪个分析、哪个候选模型参数”。
2. 区分系统级、主体级、资源级；实际、预测、计划和结算；报价、中标和执行。
3. 列出必填字段：时间、产品、方向、数量、价格、单位、币种、区域、版本和发布时间。
4. 标注哪些字段缺失会阻止某模块建模，哪些只影响增强分析，避免把所有数据缺口一概当作全项目阻塞。

**产物与判据：**问题—数据—用途对应表。每个待下载字段有明确用途；每项拟研究结论有对应数据需求。

### 2.2 实测获取渠道和保存原件

**向下执行：**

1. 分别尝试官方文件下载、文档化API和公开网页导出，确认日期选择、分页、文件格式和历史范围。
2. 对需账户、权限或收费的数据记录条件；已有公共渠道可以继续，不擅自替用户发申请或购买服务。
3. 将成功样本原样保存，记录请求范围、获取时刻、文件哈希、字节数和版本；修订另存。
4. 记录失败原因，区分页面依赖动态加载、接口错误、历史空档、权限限制和真实无数据。

**产物与判据：**每个入口至少有一个成功原始样本或可定位的失败记录；“入口找到”不能记成“数据已取得”。

### 2.3 设计覆盖边界的样本集合

**向下执行：**

1. 选普通交付日，核基本结构；选研究期起末附近日期，核历史可得性。
2. 纳入2025年3月30日、10月26日和2026年3月29日等DST边界样本，验证重复/缺少小时的表示。
3. 纳入日前粒度切换前后样本；其他规则切换由步骤1版本表补充。
4. 在实际数据中寻找负价、零激活、双向激活、强激活和异常市场日；不能把未观察到的事件当历史事实。
5. 先完成日样本，再检查2025年1月、2025年10月和2026年8月三个整月。

**产物与判据：**样本覆盖矩阵，说明每个样本验证什么。没有找到的极端事件可转为后续合成测试，不伪造历史记录。

### 2.4 解释字段和价格数量单位

**向下执行：**

1. 对照官方字段定义逐列释义；确认容量价按MW、MW·h还是交付块，数量为MW还是MWh。
2. 核“price”究竟是边际价、加权均价、单笔成交价、最高/最低价或结算价。
3. 检查空值、零值、负值、无成交、不适用的编码；验证上下方向和买卖方向。
4. 将有明确单位的样本进行一次金额复算，核是否需要乘时长及货币换算。

**产物与判据：**数据字典和单位算例。字段语义不明时不得仅凭数量级猜测并纳入正式输入。

### 2.5 对齐时钟、合同和交付区间

**向下执行：**

1. 保留来源时间文字，确认使用UTC、CET/CEST还是当地时间；分清交易日与交付日、区间起点与终点。
2. 转换为UTC起止，并另列Bucharest展示时间和UTC偏移；重复当地小时仍保持唯一标识。
3. 检查DST日真实时长，不补造缺少小时、不删除重复小时。
4. 为小时现货合同、备用交付块、QH执行和结算分别建立映射；较粗原始分辨率不插值伪装成细粒度实测。
5. 跨市场联结同一交付期，检查一对多关系是否符合合同结构，防止错误联结把现金重复放大。

**产物与判据：**统一时钟样表和合同映射。单一时序主键唯一，联结前后总MWh和应计金额可守恒。

### 2.6 样本对账与全期获取决定

**向下执行：**

1. 将日内/日度数据聚合到官方月报口径，对比成交量、均价及总量；加权方法和买卖重复记录先统一。
2. 对可比字段使用第二官方来源交叉核验，保留原值和差异原因，不盲目取平均。
3. 检查公开数据是否有原始发布时间/修订轨迹；仅有最新值的，标明不能证明历史当时可见。
4. 给每个数据集结论：可批量获取、需进一步解释、需权限、历史缺失；指定重试或替代路线。

**产物与判据：**样本质量报告与批量计划。能够解释差异并明确可用范围后再扩大；阈值应按官方舍入精度和定义制定，不能靠任意容差掩盖口径问题。

## 3. 全期数据获取与市场分析

### 3.1 分月获取20个月数据并建立清单

**向下执行：**

1. 依据样本确认的参数按数据集、产品和月份获取2025年1月至2026年8月数据；必要的交易/观察期边界另取并标明用途。
2. 每批即时记录原件、哈希、日期范围、行数和获取状态；失败批次单独补取，修订原件不覆盖。
3. 装机补充2023/2024/2025年末截面及2026最新可得截面；年报/月报用于对账，不替代分时输入。
4. 清洗结果与原始文件一一可追溯，记录处理版本和转换规则。

**产物与判据：**原始清单、规范化数据和下载缺口表。日期覆盖不是只检查最早/最晚时间，必须逐时段检查中间缺失。

### 3.2 审计全期覆盖并划定分析样本

**向下执行：**

1. 按真实时钟计算预期记录，统计每月有效、缺失、重复、修订和异常记录。
2. 分别形成日前、日内、各备用产品、基本面数据可用区间；再求各候选联合分析所需字段的交集。
3. 找到连续可用区间并记录切断原因；不把没有结算值的区间解释成电池空闲。
4. 检查单位、字段、币种、区域和产品定义的历史变化，更新版本表。
5. 保存全样本与2h/4h未来共同比较样本定义，不为不同配置各挑有利日期。

**产物与判据：**月度覆盖热图、连续区间和纳入/排除清单。每张后续图表能说明实际使用多少样本。

### 3.3 分析装机结构和变化

**向下执行：**

1. 按官方技术分类整理各年末装机，区分在运、规划、许可、分布式和自发自用口径。
2. 计算技术份额、年度净增量；储能功率MW与能量MWh分开，抽蓄与电化学分开。
3. 检查分类或统计覆盖变化能否解释某一异常增减，必要时列不可比标志。
4. 与发电量结构对照，解释“装机多”和“实际发电多”的差异；不把装机全额视为随时可调功率。

**产物与判据：**装机表、结构图、变化图及统计边界说明；每个截面有同一时点和来源。

### 3.4 分析负荷、实际出力和跨境交换

**向下执行：**

1. 计算月度电量、平均/峰值/谷值负荷、峰谷差、负荷持续曲线和爬坡分布。
2. 按季节、工作日/周末和当地钟点统计；缺失不均时列出各组样本数。
3. 形成分技术出力堆叠图和季节典型日，抽水耗电与抽蓄发电单列；实际与预测另列。
4. 分边界整理进口/出口、物理流和商业计划，核净进口符号；不把不同类型交换相加。
5. 核对系统发用电平衡，并解释净/毛、损耗、抽水、分布式覆盖和统计差异，避免强行将差额压为零。

**产物与判据：**供需季节图、典型日图、交换图和总量对账说明，为电价解释提供同时间样本。

### 3.5 分析日前和日内价格及流动性

**向下执行：**

1. 计算各市场均价、中位数、分位数、波动、极值、负价频次、连续低价长度和日内峰谷差。
2. 制作月份×钟点价格热图，比较四季、工作日和市场制度切换前后；粗细粒度比较采用一致权重。
3. 逐轮比较IDA与DA价差和成交量；连续日内按可得成交时刻/产品分类，不能把全日均价当随时可成交价格。
4. 观察连续2小时/4小时低价或高价窗口、跨日价差及其频率，作为时长价值的描述性证据。
5. 区分价格机会与可实现收益：此阶段不考虑完整设备/市场约束的价格差统计不命名为电池回测收益。

**产物与判据：**现货价格统计、热图、价差/成交量图，以及对2h/4h机会的研究解释。

### 3.6 分析残余负荷、价格驱动和典型事件

**向下执行：**

1. 定义基础残余负荷候选指标“总负荷−风−光”，先核分布式覆盖和净/毛口径；其他扣减另命名。
2. 对齐残余负荷、电价、分技术出力和净进口，计算散点、分箱和相关性，并按季节/时段分组。
3. 选取真实负价、高价、低风低光或大交换日，按同一规则展示其前后过程，避免只挑支持预设结论的事件。
4. 若加入水文、停机、燃料等解释变量，补充其来源、可用时点和缺失说明。
5. 查报价曲线是否含可识别技术/机组及历史映射；证据不足时仅报告供需关联，不宣布找到定价机组。

**产物与判据：**残余负荷分析、事件卡和证据限制；统计相关、机制解释与因果结论清楚分开。

### 3.7 分析备用容量市场

**向下执行：**

1. 按产品、方向、交付块统计需求、报价、中标、价格分布和支付金额；各类价格分别计算。
2. 观察季节、钟点、工作日差异及规则切换；识别报价不足、需求变化和高价时段。
3. 在分子分母可比时计算需求/报价、中标/报价等市场供需指标，解释零分母和重复投标。
4. 如有名册/中标主体数据，分析集中度和参与规模；主体数量不代表竞争有效程度。
5. 比较现货价格与容量价格的关系，提出机会成本解释；不能直接把统计比例作为单站中标率。

**产物与判据：**逐产品容量价量图、市场规模表、供需指标及其建模可用性说明。

### 3.8 分析激活能量、不平衡及跨市场联系

**向下执行：**

1. 分产品和方向统计激活能量、价格、频次、持续时长与连续激活事件。
2. 比较容量中标与激活数据是否属于相同产品、总体和区间；不一致时不直接相除。
3. 统计双向激活、负价格、极端偏差价格及其对应的供需事件；分清系统请求和最终交付。
4. 分析激活后的能量恢复需求与日内交易窗口是否相容，形成待在策略阶段检验的问题。
5. 将跨市场联系分为已由规则证明的约束与仅由历史数据发现的关联。

**产物与判据：**激活/偏差分析、连续履约事件表、候选情景输入说明；不以QH净激活为零推定全过程SOC可行。

### 3.9 形成面向模型的数据结论

**向下执行：**

1. 按日前、DA+IDA、联合备用/激活、现实信息策略四类用途，列出数据满足程度。
2. 对2h/4h提炼低价充电窗口、持续高价、备用持续性和激活恢复方面的研究问题，不提前得出谁收益更高。
3. 给每个待补数据指定影响、优先级和关闭方式；基础完整但增强缺失的模块可提出限定范围方案。

**产物与判据：**建模数据适用性矩阵，进入步骤4审核；不能只用“价格数据齐全”判断联合模型已具备条件。

## 4. 研究报告与审核

### 4.1 将专题成果收拢到十章报告

**向下执行：**按既定十章提纲，把机构/准入/规则/结算/基本面分别放到对应章节；补机构图、交易时间线、产品表和数据覆盖；术语集中解释。尚未进入策略阶段的第8章保留候选设计，未求解的第9章注明尚未测算并列后续验证字段。

**产物与判据：**研究报告初稿。读者能从资格、交易、履约一路读到结算和数据证据；不依赖零散聊天理解核心结论。

### 4.2 建立结论到证据的逐条追溯

**向下执行：**给关键陈述标F/I/A/U；F连接到正式来源条款或可复现数据表；I写出推理与限制；A注明取值依据、用途和敏感性；U注明缺什么证据和影响范围。核对所有数字的单位、时间、地域和版本。

**产物与判据：**结论—来源—适用期—章节对应表，无来源的关键规则不能以事实口吻进入结论。

### 4.3 做跨章节一致性检查

**向下执行：**逐一对照准入与产品范围、容量与能量付款、时间线与数据发布时间、计划/实测/偏差定义、网络费与目标收益范围、2h/4h参数口径。用步骤1.7算例贯穿全报告，检查同一概念有无不同名称或矛盾数值。

**产物与判据：**一致性问题清单和修订记录；不能让某章标待确认、另一章却当确定规则使用。

### 4.4 开展独立只读审核并修订

**向下执行：**主线程直接分派research_reviewer审核范围内研究和证据，禁止下级委派；审核者提交问题、证据定位、影响范围和修复要求。主笔补证/修订，审核者复核；不由审核者直接修改成果或宣布下一阶段启动。

**产物与判据：**独立审核记录与问题关闭表。问题仅可凭补证、修正或明确移出范围关闭，不能以“以后再说”标成已解决。

### 4.5 主线程验收并形成建模交接包

**向下执行：**明确哪些产品/历史期已确认，哪些以假设情景研究，哪些暂不纳入；冻结研究报告版本。交接包包含资格矩阵、事件时间线、结算科目、约束候选、数据适用性、未决问题和验收结论。

**产物与判据：**限定范围的研究验收。未决增强专题可保留，但影响已纳入产品资格、结算或物理履约的关键问题必须解决或移出批准范围。

## 5. 策略、MILP数学说明与输入输出规范

### 5.1 先明确模型回答的问题

**向下执行：**

1. 区分“研究事后条件收益”“研究当时可执行策略”“解释2h/4h差异”等目标，决定首版和扩展范围。
2. 根据步骤4验收选择市场组合，保留日前基准和逐模块比较；未知产品不自动加入。
3. 定义目标为毛现金收益还是扣哪些成本后的净额，以及是否包含偏差/退化/终端估值。
4. 明确数据区间和2h/4h共同比较口径；实际功率值未定时保留符号和适用规模限制。

**产物与判据：**模型范围与目标说明。所有收益名称都能对应明确成本边界和信息条件。

### 5.2 写出交易者逐时点能做什么

**向下执行：**

1. 把官方时间线改写成决策表：时点、已知信息、允许决策、已锁定承诺、后续可能变化。
2. 明确现货买卖、容量报价、能量支持报价、恢复SOC、偏差处理各由谁控制。
3. 对中标和激活分别确定外生数据、代理假设或场景；不能让优化器随意挑选只赚钱的激活。
4. 决定滚动视野、执行段、承诺结转和期末边界；先用一天/两天事件示例验证无时序冲突。

**产物与判据：**策略和假设登记，经审核后再进入数学。缩短优化窗口本身不等于取消未来信息。

### 5.3 定义2h/4h设备及项目参数

**向下执行：**确定额定与可用E、充放P、AC/DC口径、SOC、效率、辅助用电、接网限额、可用率、爬坡、退化和循环预算。将未知量分为工程待定和候选假设。两种时长优先同P比较，并解释循环分母及固定成本是否随E变化。

**产物与判据：**参数表；每个值有单位、来源/假设和适用范围，不直接继承西班牙数值。

### 5.4 建立集合、变量、合同映射和收益目标

**向下执行：**

1. 定义物理时段、合同、拍卖事件、备用交付块、方向和必要情景索引。
2. 定义净买卖头寸、申报/中标容量、充放功率、SOC和互斥二元变量，区分决策、外生输入及派生量。
3. 建立小时/交付块到QH的映射，使用真实时长；已成交合同作为状态或冻结变量。
4. 根据结算账本写目标函数，每项注明币种、MW/MWh、计价周期和正负方向；终端价值独立展示。

**产物与判据：**数学符号表和目标函数；不存在未定义变量、量纲不一致或同一笔现金重复计入。

### 5.5 写物理及循环约束

**向下执行：**逐条写充放互斥、方向功率与接网限制、SOC递推和边界、效率/辅助用电、初始和最终条件、吞吐与EFC。用纯充、纯放、空闲、满电/空电四类小例检查；明确AC功率和DC电量换算。

**产物与判据：**物理约束组与手算记录，能量守恒。循环和退化属于明确项目参数/假设，不称为统一市场规定。

### 5.6 写交易和备用容量的耦合约束

**向下执行：**

1. 连接各市场增量成交与基础计划，锁定已成交订单；关闭不允许交易的时点。
2. 按已审产品规则加入最小规模、块长度、步长、方向关系和报价义务。
3. 连接基准出力与上下备用功率空间，处理减充、增充、减放、增放及跨零的适用边界。
4. 多产品叠加时按可同时发生的履约要求检查共享功率/能量，不无条件重复出售同一能力，也不无证据强行禁止所有叠加。
5. 将持续能力、SOC预留和恢复要求放入适用约束，每项连接规则或假设编号。

**产物与判据：**市场耦合约束组和来源表。模型中可中标的承诺，必须能在相应履约情景中物理交付。

### 5.7 写激活、偏差和费用处理

**向下执行：**将激活请求/代理映射作用到实际功率、SOC、EFC和现金；确定必要子步/路径以检查时段内越界。按官方结算定义连接最终计划、激活调整、计量和剩余偏差。将损耗、自用电和可减免回送电量的费用计量分别表示；资源级证据缺失采用明确情景。

**产物与判据：**激活与结算约束、正负价格算例。不存在“收到激活收入但不消耗/存入电量”或激活和偏差重复付款。

### 5.8 写信息条件、滚动和数学审核

**向下执行：**

1. 完美信息与预测输入分别定义；现实信息版本检查发布时间，必要时设置情景共同决策约束。
2. 定义SOC、未交付合同、备用承诺和循环预算的跨窗口继承，只有执行段计收益与循环。
3. 检查末端数据、缺口断段、终端SOC/估值和观察期，不把观察期收益计入正式期间。
4. 检查线性化、Big-M来源、分段费用和变量乘积；形成约束来源矩阵。
5. 完成数学手算与独立审核，按问题修订，再由主线程验收。

**产物与判据：**可审计MILP数学说明和数学审核记录。未求解时不声称模型可行性或收益已获数值验证。

### 5.9 在数学通过后锁定输入输出规范

**向下执行：**

1. 定义输入表：设备、市场价格、合同、容量、激活、费用、版本、事件时钟、初始状态；逐字段写类型、单位和来源。
2. 区分决策输入与事后结算输入，定义可用时刻、缺失拒绝/关闭模块/断段规则和修订选择。
3. 定义输出：订单、计划、实际功率、SOC、备用、激活、偏差、逐科目现金、EFC、覆盖、求解状态和版本信息。
4. 规定2h/4h共同样本、月度/小时/滚动年、每MW/每MWh等展示口径；保留负现金、空值和覆盖率。
5. 提供小型输入输出示例和字段映射，随后才交给代码阶段实现。

**产物与判据：**输入输出规范、示例及交接清单。每个公式参数有输入来源，每项重要结果有输出字段；尚缺正式数据的参数明确标注。

## 6. 一个子任务继续向下拆解的例子

以“研究aFRR容量采购”为例，不以找到一个容量价格网页作为完成，而是依次留下以下记录：

| 操作 | 实际要查或做什么 | 留下的证据 |
|---|---|---|
| A 确认产品 | 官方本地名称是否对应aFRR；是否区分容量与能量 | 产品定义条款及翻译 |
| B 确认资格 | 独立储能/聚合资源是否可参与、最小数量、预认证 | 资格矩阵和未决项 |
| C 确认时间 | 需求发布、关门、中标公布、交付起止 | 带时区的事件表 |
| D 确认报价和出清 | 报MW还是MWh、上下方向、数量块、价格和接受机制 | 规则卡和正式条款 |
| E 确认付款 | 每MW每小时还是每块；统一还是逐报价支付 | 单位表和付款公式依据 |
| F 确认义务 | 中标后可用性、能量支持、持续能力和罚则 | 履约条款及候选约束 |
| G 取真实样本 | 同一招标的需求、报价、中标、价格和时段 | 原始结果及下载记录 |
| H 对账 | 复算样本可推导的金额，与公布字段比较 | 手算表、差异和解释 |
| I 判断能否建模 | 本站接受机制、激活和数据是否足够；需哪些假设 | 规则/假设/未决三类交接 |

例如样本若明确价格是RON/(MW·h)，才用“中标MW×价格×小时”复算；若价格按整块报，则不能重复乘小时。这里仅说明量纲核验方法，不预判罗马尼亚某产品的实际计价规则。
