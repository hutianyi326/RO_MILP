# 电量和现金结算手算例

目的：验证方向、单位和避免重复计收。除第4节明确引用官方程序的跨月电量示例外，数值为 **A03 假设**，不是罗马尼亚历史成交、官方费率、预测或本站收益。统一采用 RON、MWh；售电/净注入为正。算例针对一个独立 PRE，无跨 PRE 转移、进口出口或拥塞补偿；税费、月度中性化、履约其他条款均需另记，不能据此宣布净收益。

**F依据**：BSP art.90—93（E14）确定标准激活承诺量及正负价格收付款；BRP art.147—158、167（E14/E52）确定净合约与净计量的偏差；2025-04-01之后最终价格分支见E17修改art.195。例中价格直接给定适用最终价，不用估算价替代最终价，也未自行重建系统中性化。

## 1. 基础账本

假设一个15分钟区间，DA售2.0MWh@300；ID购0.5MWh@250。净现货售电 Qspot=1.5MWh；现金 Cspot=2×300−0.5×250=475RON。2MWh/0.25h=8MW，购电0.5MWh/0.25h=2MW，净头寸6MW；该例不代表只有2MW额定功率的设备可实现此头寸。

| 情形 | PE承诺上/下调(MWh) | 净合约(MWh) | 净计量(MWh) | 偏差(MWh) | 激活现金(RON) | 偏差现金(RON) | 现货+激活+偏差小计(RON) |
|---|---|---|---|---|---|---|---|
| 无激活、完全交付 | 0/0 | 1.5 | 1.5 | 0 | 0 | 0 | 475 |
| 上调、少交0.1 | 0.5/0 | 2.0 | 1.9 | −0.1 | 0.5×800=400 | −0.1×1000=−100 | 775 |
| 下调、正价 | 0/0.4 | 1.1 | 1.1 | 0 | −0.4×200=−80 | 0 | 395 |
| 下调、负价 | 0/0.4 | 1.1 | 1.1 | 0 | −0.4×(−200)=80 | 0 | 555 |
| 上调承诺0.5、少交0.2 | 0.5/0 | 2.0 | 1.8 | −0.2 | 400 | −0.2×1000=−200 | 675 |
| 同一ID双向承诺 | 0.5/0.4 | 1.6 | 1.6 | 0 | 0.5×800−0.4×200=320 | 0 | 795 |

I：表内0.5MWh上调“承诺”进入合约基准，不用实际少交的电量替换它来抹掉偏差。双向承诺的0.9MWh绝对电量与0.1MWh净电量不同，实际分配、响应曲线、可行功率和SOC仍需验证；该行只检验现金账本，不证明这些指令在此设备可行。

## 2. 负现货价与双偏差价

假设购1MWh@−100RON/MWh，购电现金为−1×(−100)=+100RON；不是支出−100后再次计收入100。若上调0.5MWh@−800，BSP现金−400RON；负下调价则如表内+80RON。

假设某ID最终双价已依法确定：缺额价1000、盈余价100RON/MWh。相同−0.1MWh缺额现金−100；+0.1MWh盈余现金+10。不能将两者都按估算单价300计算。若官方最终两方向相同，应保存为相同的已公布价格，不自行推断制度分支。

## 3. 容量单位敏感性，尚未关闭U06

纯单位假设：确认能力2MW，价格40RON/(MW·h)，一个QH可用。容量现金=2×40×0.25=20RON；上调例小计775+20=795RON。若数据字段实际为每块RON/MW，则应为2×40=80；两者不能混用。

**这不是正式容量收入公式批准**。新增E66正式FCR报价程序已明确数量为每方向R、价格lei/hMW，不能将总带宽2R作为同一报价量计费。FRR/RR程序E67仍写lei/MWh，运行字段、历史合同和确认发票须继续核对U06；上述两种单位结果用于检查，不是自由选择模型输入。

## 4. 月度网络减免与SOC桥接

依据E23和E50 §5.2.1.1，仅举独立储能月度边界。假设月初月末SOC一致，取电Eex=100MWh、返送Ein=90MWh，差额10MWh进入有关费用基础；并非所有100MWh一律零网络费。假设相关合并单位费率为50RON/MWh，则现金成本500RON。50是A数值，不能用作监管费率。

F：E50 p9及p10 §5.3.1表3明确跨月调整。官方电量示例为上月Eex100、Ein80、Etr20；当月Eex0、Ein18、Etr−18；两月Etr合计2。这里的Ein对应原文Ei。假设（A）两月同一单位费率50RON/MWh，仅该电量费用科目分别为1000与−900RON，合计100RON；负值是跨月减免调整，不能按零裁剪。该示例电量来自正式程序，50费率仍为假设。

I：负计费电量不保证含固定费、TG、税项及其他费用的整张账单为负；变动费率和具体网络方历史执行仍待U09。损耗、辅助负荷及TG等另按适用规定，不把减免量当作零物理损耗。

## 5. 本例的检查断言

每行核对：净合约=Qspot+up−down；偏差=净计量−净合约；激活现金=up×pup−down×pdown；小计=Cspot+Cact+Cimb。价格或方向可以改变现金符号，电量仍按定义；容量现金是另一个科目。程序化复算输出见项目verification.json；检查通过只证明这些假设数字算术正确，不证明历史规则、产品资格或真实可执行收益。
