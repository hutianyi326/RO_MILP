# 罗马尼亚第三步八组缺口补查报告

研究范围保持2025-01-01—2026-08-31，通用独立储能P参数、2h/4h。主线程补充取证，独立Astra high审核。本报告及附件单独存档，不修改已审规则、样本、全期报告和固定基线。正式验收与完整第三步退出分开；本轮所有模型、策略、实现、回测、as-of门禁保持false。

主要进展是取得真正的偏差价格版本、扩展全期日内选日网页、确认容量月报的计价单位、验证日前双币种样本，并补充费用和口径证据。八组仍有公开来源无法直接关闭的依赖；逐项状态和下一份验收证据见[关闭台账](closure_ledger.md)。官方机构、文名、日期、URL、页码与访问时刻见[来源目录](source_directory.md)及evidence_register.csv。F=官方事实；I=解释；A=检查或候选建模假设；U=未确认。

## 1. 偏差价格与系统量

**F** Transelectrica结算目录提供统一、缺额、余量价格和系统偏差量。本轮取得20个月191份目录版本；价格表头为lei/MWh，系统量表头为MWh，与原先系统成本附件不同（GC01；每个文件日期/URL见版本目录）。正文打印日期、VM/VMA标签、日期列、INT序号和原生零/破折号逐份保存。系统量不是MW，不能再乘0.25。

**I/A** 本次可见版本按正文打印日期选择20月×4种80份，用于事后版本比较；该选择不证明不可再修订或历史发布时刻。原生日期×INT与A物理日数量形成58,364个候选QH，不批准UTC顺序或双价结算规则。提取了557,318个全版本格点；417,006个格点经第二种矩形方法检查，262个矩形遗漏经独立PDFium单元定点确认恢复。未修复提取另存，原始PDF未改。

最新观察表中，47,825候选格点只有统一价，10,315只有缺额/余量结构，210全部价格缺失，14为其他结构。前两种名称仅描述非空关系，不代表已核准规则模式。111组相邻版本比较中91组有数字变动，说明不能把本次最新值当历史决策时输入。

**U** 官方原件有10份末尾行不足的价格表，2026-02的部分原件止于INT092，影像已核，不能填0；44份系统表主标题仍印“Octombrie2024”而正文日期列属于目标月；两处目录/正文日期冲突。210无价、14特殊结构、时钟/符号/模式、生效链、PRE/本站分配、实际账单和终版定义仍未齐。不能计算真实偏差现金。详见settlement_analysis_summary.json与source_anomalies.csv。

## 2. IDA和连续日内

**F** 公开网页通过匿名表单选择日期，CSRF来自公开页面，不使用账户。2025-01—2026-08的608个日期逐一请求三轮IDA及PT15、PT60连续日内；已有样本以同一原件复用。每份返回日期、数字行、空格/破折号、产品文字和原件哈希均审计。三轮IDA共有175,092个原生时段行，其中69对数字价量。连续日内原件经完整单元格流提取，共**3,741,324个网页出现记录**：PT15选择器2,180,829个，PT60选择器1,560,495个；129,792个原生产品组的rowspan声明逐组与价量三元组及提取数吻合。全部608日期×3类查询格式、单元格消费和日期核验见[intraday_analysis_summary.json](intraday_analysis_summary.json)，不证明市场数字完整性。IDA单位EUR/MWh与MW；连续日内单位EUR/MWh与MWh（GC06/07）。

**提取修复记录** 第一轮独立审核FAIL，发现仅遍历表格行会遗漏位于行外的连续价量单元格。首轮“129,792个出现记录／解析错误0”的完整提取结论撤回：该数实际只对应每个产品组的首条，遗漏3,611,532个已公开出现记录，属于提取缺陷。首轮冻结包和[失败意见](review_round1.md)保留。修复后按完整单元格流提取，另以rowspan游标遍历逐条核对输出的原文、顺序、重复值、产品及单元格定位；验证记录另存，不运行或导入原提取脚本。PT15的2025-03-24原件确实只有表头，登记“无已发布出现记录”，不能认定零交易。

**I** 完整查询范围不等于完整交易数据。IDA大多数轮次只有“-”或前半日空格，0.000页脚也不能独立证明无交易、取消或没有竞价。数值对只在有原生数字时记录；IDA3前段空白保留原状。连续日内原生caption为“Trades concluded in 日期”，仅核对成交归属的查询日期，不把它当完整交付日期。60选择器实际表头为Hourly/Block Trades，不能假定每条都是1h产品；buy/sell、块与_XB标签按出现次序保存，不人为去重，不假定源记录就是带身份的独立成交。MWh已是电量，不再乘0.25。

**F/U** OPCOM2025-03-14公告指RO-HU、RO-BG从交易日2025-03-18纳入IDA及统一保证金调整；2024-05-31公告已有2024-06-13规则运行安排。这不能写成“罗马尼亚IDA从2025-03-18才存在”。2026-03-23公告说明2026-03-29有23小时/92个15min间隔（GC14）。这些事件补充历史线索，但未关闭全部GCT/取消/回退与程序版本。公开表仍缺trade_time、trade_id、完整交付身份、盘口及历史发布版本，不能据此建立现实可执行的日内收益。

## 3. 容量价格、实际支付与激活

**F** TSO2025-08 STS月报p4说明从2024-09按pay-as-bid，获选全部或部分量得到自己的报价；p5及p8—12容量价格为lei/hMW，合同金额、未履约罚款及实际成本分别列示。FCR按对称带宽列示，不能自行认为双向需乘2；p5 FCR均价346.68lei/hMW，合同量月均90.94MW、合同成本23,456,500lei、罚款0；aFRR上调合同成本3,693,678lei、罚款19,528.58lei、实际成本3,674,149.42lei（GC02）。这些是系统月报，不能当本站收入。

**F** p8注释指出公开平台价格为报价的算术平均，月报相应小时表按合同容量加权。该说明不自动解释API的每个averageAccepted/averageOffered字段，更不证明平均价可乘本站容量得到支付。FCR合同Art16—19要求按实际实现容量和Annex3价计算、按月开票并处理罚款；Annex3价格栏为lei/h×MW（GC05，原Word保留，只读转换便于核对）。

**U** FRR采购程序p11§8.5.3仍直接印lei/MWh，p12§8.7.5为中标报价合同。与月报容量单位存在文字冲突，不能未经勘误把程序改写成已确认正确单位。已知容量月报/合同单位只关闭对应子项；API每字段、全部历史采购、资源受理报价、履约量、罚款/发票、激活价单位及本站分配仍缺。系统激活MWh不能直接变成本站充放电或SOC。

## 4. 容量覆盖、DST与供方

**F/I** STS月报明确FCR竞争性日拍卖从2025-06开始（GC02）。因此2025-01—05公开拍卖统计缺段有采购范围解释；该证据未说明早期FCR没有服务、没有合同或没有付款。

复用69,327产品小时，按100产品月和3个换时日重新检查。2025-03-30 FRR每产品23小时，FCR没有原生拍卖行；2026-03-29五产品各23小时；2025-10-26五产品各24小时，对当天25物理小时存在一小时缺口。保留UTC和本地偏移，不补零、不复制邻时段，合同边界语义仍待TSO核实。

供方复算57,202小时吻合、12,125未吻合，逐产品月定位见capacity_month_product_coverage_supplement.csv。月报有22个FSE名单与HHI，但这是2025-08截面；没有全期有效期法人/EIC/聚合资源映射，不能把发布标签直接当法人集中度或本站资格。

**I/U** 这些说明帮助解释汇总边界，不定义TSO SCADA每一技术字段。SCADA直接时钟、净/毛、抽蓄泵耗、分布式和储能充放电及2026-07-17错日期原件修正仍待确认。同表恒等式不是独立全国能量平衡，商业计划不是物理流，聚合年报不能补分时NTC/ATC。
