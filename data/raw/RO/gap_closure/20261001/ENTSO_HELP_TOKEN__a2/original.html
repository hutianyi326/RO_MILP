How to get security token?

January 28, 2026 09:25 Updated

Security token is required to use web API. Please follow the process shown in below diagram to generate a security token:

 

 

1- Register Transparency Platform

1.1- Go to:

Production environment: https://transparency.entsoe.eu/ or

Test environment: https://iop-transparency.entsoe.eu/ (does not contain as much data as the Production environment)

and click on the "Sign In" button:

1.2- Click register link

 

1.3- Register

 

1.4- Verify account via URL sent to the registered email address

2- Send an email

Send an email to transparency@entsoe.eu with “RESTful API access” in the subject line and the registered e-mail address in the body.

3- Wait for confirmation e-mail

You will be granted within 3 working days and will receive an email

4- Login Transparency Platform and create a security token

4.1- Click "My Account"

4.2- Generate a (new) token

If a token is already generated, a warning message will be displayed:

 

 

5- You can start using the RESTful API
